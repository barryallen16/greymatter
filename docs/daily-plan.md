# The Plan — Daily Schedule + 90-Day Roadmap (Aug 25 → Nov 2026)

**Non-negotiable rule #1:** Fixed wake time every day, including weekends. The hours can shift ±30 min, but the *sequence* never changes.
**Non-negotiable rule #2:** Phone charges overnight OUTSIDE the bedroom. First screen you touch is LeetCode.
**Non-negotiable rule #3:** Track every day in one line: date, problems attempted, solved-without-help Y/N, project task done, applications sent. One notebook or one sheet. No fancy tools.

## The 90-Day Roadmap

### Phase 1 — Foundations + Cleanup (Aug 25 – Sep 30)
**DSA goal:** 72 → ~180 problems. Order (NeetCode 150 spine):
1. Finish Arrays/Hashing + Two Pointers + Sliding Window (your gaps show in tags)
2. Stack + Binary Search (you have some) → Linked List (ZERO so far)
3. **Trees (all)** → Heaps → Backtracking
4. Start Graphs: BFS/DFS → Topo sort → Union-Find
Rule: 25-min struggle cap per problem → editorial → implement → mark for next-day redo. Never skip the redo.

**Project goals (only these):**
- Week 1 weekend: revoke Telegram token + 2 OpenRouter keys, purge `.env` history, scrub middleman PII, DELETE Vadachennai/project01/salim/TensorTonic-Solutions
- Weeks 2–4: kaggle-automation → Dockerfile + GitHub Actions CI + README architecture diagram
- FitCheck: either RUN the LoRA SFT (dataset exists) or rewrite README claims. Pick one by Sep 15.

### Phase 2 — Volume + Proof (Oct 1 – Oct 31)
**DSA:** 180 → ~260. Graphs mastery → 1-D DP → 2-D DP → Greedy → Intervals. 2 contests/week.
**Projects:** Ship sivabharani-comments search layer (Meilisearch + tiny UI — you've done this twice already). Add tests to fitcheck-app's stale suite.
**Interview prep starts:** 1 mock interview/week (Pramp / peers / record yourself). Behavioral stories written: 6 STAR stories mapped to your repos (the 42-item wardrobe question, the fake-suspense sleep, why eval harness).

### Phase 3 — Peak Application Season (Nov)
- Applications: 15–20/week. Chennai product cos + GCC GenAI drives open up — don't skip them.
- DSA maintenance: 2/day + both contests.
- Every interview → debrief doc within 24h: what was asked, what you fumbled, drill it next day.
